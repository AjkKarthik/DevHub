Reactive Forms + Services

Key Concepts

  • inject(Service) — modern DI without constructor params
  • FormBuilder.group() — create a typed FormGroup
  • Validators.required / minLength — built-in validators
  • form.invalid / control.errors — read validation state
  • Service uses signal() + computed() — component reacts automatically
