The Challenge Regex Lost Its Backslash

The Challenge's formatProduct used /\s+/g inside a JavaScript template literal, which turns \s into a plain s. Readers saw replace(/s+/g, '-'), and that code produces widget pro, not the widget-pro the snapshot expects.
