apply_chat_template Returns a Dict in Transformers 5

The manual generation example passed the result of apply_chat_template(..., return_tensors="pt") straight to model.generate and read inputs.shape. In transformers 5 that call returns a BatchEncoding, which has no shape, and generate failed with an AttributeError.
