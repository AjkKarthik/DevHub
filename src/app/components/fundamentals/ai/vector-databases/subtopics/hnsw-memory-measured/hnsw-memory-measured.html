HNSW Memory Is Not N·M·d

The page gave HNSW memory as O(N·M·d) floats. HNSW stores each vector once and adds a list of neighbour IDs; measured with FAISS, M=32 costs about 6.4 KB per 1536-dim vector, not 196 KB.
