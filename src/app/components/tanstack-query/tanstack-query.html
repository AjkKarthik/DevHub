Why TanStack Query?

Caching

Deduplicated fetches — multiple components sharing the same queryKey share one request.

Stale-while-revalidate

Returns cached data instantly, then refetches in the background when staleTime expires.

Reactive keys

Query key is a function — reads signals, so changing selectedId() automatically re-fetches.

Mutations

invalidateQueries on success keeps UI in sync without manual state management.
