The Recursive-Yield Tree Traversal Is Secretly O(n²)

The main page's own InOrderFrom recurses with a foreach-wrapped yield return at every level — a well-documented C# performance trap. Verified against Eric Lippert's own analysis: this is O(n log n) for a balanced tree, and genuinely O(n²) for a degenerate one.
