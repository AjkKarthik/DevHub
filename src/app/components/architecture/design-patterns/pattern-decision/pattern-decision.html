Quick Anti-Pattern Checklist

  • Singleton abuse — global mutable state? Use DI-registered singleton + interface instead.
  • IQueryable leak — returning IQueryable from a repository? Use IReadOnlyList or Specification.
  • SaveChanges in repository — committing per-repo? Move to Unit of Work / service layer.
  • Domain logic in controller — business rules in HTTP handlers? Move to domain entities.
  • Non-idempotent Saga steps — message retried twice? Add idempotency key check.
  • Captive dependency — Scoped injected into Singleton? Use IServiceScopeFactory.
  • Speculative generality — building plugin systems nobody asked for? YAGNI.
  • Premature abstraction — extracting an interface for one implementation? Wait for the second.
  • Dark mode via media query — never @media (prefers-color-scheme) — use :host-context(body.dark).
