Where this fits

Snapshotting (the previous subtopic) and upcasting solve two different problems that both stem from the same fact — events are permanent. Snapshotting is about how EXPENSIVE replay gets over time; upcasting is about what happens when the SHAPE of an old event stops matching what current code expects. Both leave the stored event log completely untouched.
