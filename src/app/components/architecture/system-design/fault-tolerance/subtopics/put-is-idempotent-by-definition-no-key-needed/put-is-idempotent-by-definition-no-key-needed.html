PUT Is Idempotent by Definition — It Doesn't Need a Key

The page grouped PUT with "idempotency key" required — verified against RFC 7231 that PUT, DELETE, and GET are idempotent by HTTP definition; the idempotency-key workaround is specifically for POST.
