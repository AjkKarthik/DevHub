Elasticsearch’s Default Shard Count Has Been 1, Not 5, Since 7.0

The page's Q&A stated Elasticsearch indexes default to 5 primary shards — verified via WebSearch that this changed to 1 in Elasticsearch 7.0 (2019), and the old default has kept circulating in reference material ever since.
