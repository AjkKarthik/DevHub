30 Shards Doesn't Divide to 33M Docs Per Shard

The Challenge solution stated "500M docs / 30 shards = ~33M docs each" — the real division is ~16.7M; the 33 actually comes from a separate storage-size calculation (1 TB / 30 shards), mislabeled as a document count.
