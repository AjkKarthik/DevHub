NotReady Eviction Is Taint-Based, Not a Fixed Global Flag

The main page's own QnA describes pod-eviction-timeout as a single global timer. Since Kubernetes 1.13, eviction is taint-based and configurable per pod via tolerationSeconds — same default, different mechanism.
