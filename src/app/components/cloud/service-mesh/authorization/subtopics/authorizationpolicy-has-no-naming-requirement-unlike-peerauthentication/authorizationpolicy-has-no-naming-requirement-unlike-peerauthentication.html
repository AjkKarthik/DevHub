AuthorizationPolicy Has No Naming Requirement, Unlike PeerAuthentication

Learned that a mesh-wide PeerAuthentication must be named "default"? That rule does NOT carry over to AuthorizationPolicy — any name works, and multiple mesh-wide policies apply cumulatively.
