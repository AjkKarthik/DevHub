Kubernetes Secrets Are Base64, Not Encrypted, By Default

The main page lists "Kubernetes Secrets (with encryption at rest)" as if it were automatic — Kubernetes' own docs state Secrets are stored unencrypted in etcd by default; encryption is a separate, opt-in step.
