Kubernetes Has No Built-In Namespace TTL

The main page's own "add a TTL (destroy after 24h of inactivity)" reads as a simple option — Kubernetes' only built-in TTL controller is scoped to finished Jobs, not namespaces, and has no concept of inactivity.
