Traceroute Defaults to UDP, Which Firewalls Often Block

The main page lists -T and -I as bare options — plain traceroute actually sends UDP probes to ports 33434+, and a row of asterisks usually means a firewall is silently dropping that specific pattern, not that the path is down.
