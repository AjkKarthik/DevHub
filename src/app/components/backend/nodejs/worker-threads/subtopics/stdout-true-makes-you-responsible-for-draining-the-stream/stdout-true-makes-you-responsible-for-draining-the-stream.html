stdout: true Makes You Responsible for Draining the Stream

By default a worker's console output is auto-piped to the parent's own stdout — opting out with stdout: true hands you a stream that goes nowhere until you read it yourself.

Code Examples

Where this fits

Together with the previous two subtopics, this rounds out a set of worker-thread defaults that look automatic until you opt out of them — process.env stops syncing, terminate() stops being instant, and now stdout stops forwarding itself — each one trading a convenient default for explicit control the moment you ask for it.
