AddProject Type Parameter Requires a Build, Not Just a Project Reference

Projects.MyApp_Api isn't hand-written — it's generated at build time from the AppHost's ProjectReference entries. Add a new reference and the type simply doesn't exist yet until the AppHost is actually built.
