What EF.CompileQuery Actually Eliminates

The main page implies every call to an uncompiled query pays full LINQ-to-SQL translation. It doesn't — EF Core already caches query plans by expression shape. Compiled queries eliminate the cache LOOKUP itself, not translation that would otherwise repeat every call.
