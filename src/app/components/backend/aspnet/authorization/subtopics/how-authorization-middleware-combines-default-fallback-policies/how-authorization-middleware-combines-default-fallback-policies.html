How Authorization Middleware Combines Default & Fallback Policies

FallbackPolicy is not a baseline ANDed under every other policy — it only runs when an endpoint has NO authorization metadata at all. A custom policy that forgets RequireAuthenticatedUser() bypasses it entirely, even with a strict FallbackPolicy configured.
