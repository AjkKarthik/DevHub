Testing Allocation Regressions With GetAllocatedBytesForCurrentThread

BenchmarkDotNet is too slow to run on every commit. GC.GetAllocatedBytesForCurrentThread() gives a fast, CI-friendly allocation gate that catches gross regressions — like the main page's own O(n²) string concatenation example — without full statistical rigor.
