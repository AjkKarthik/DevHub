Server GC Heap Count Follows Perceived, Not Actual, CPU Limit

"One heap per logical core" depends on the container correctly reporting its CPU allocation. A pod with requests.cpu but no limits.cpu can let the runtime perceive the host's FULL core count, creating dozens of unnecessary GC heaps.
