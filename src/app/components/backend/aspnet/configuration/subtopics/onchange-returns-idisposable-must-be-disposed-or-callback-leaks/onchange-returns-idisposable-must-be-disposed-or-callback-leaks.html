OnChange() Returns an IDisposable That Must Be Disposed — Otherwise the Callback Closure Leaks Forever

The main topic page's own FeatureFlagService stores OnChange's result in a field named "_listener" but never disposes it. That field name is a hint at intent — the singleton IOptionsMonitor holds the callback forever unless the returned IDisposable is explicitly disposed.
