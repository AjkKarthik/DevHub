Pruning Data Protection Keys Invalidates Still-Valid Time-Limited Tokens

A time-limited token's own expiry clock is a separate promise from whether the key that encrypted it still exists in the key ring. Prune that key early and every still-young token encrypted with it fails at once — looking identical to routine expiry under a bare catch.
