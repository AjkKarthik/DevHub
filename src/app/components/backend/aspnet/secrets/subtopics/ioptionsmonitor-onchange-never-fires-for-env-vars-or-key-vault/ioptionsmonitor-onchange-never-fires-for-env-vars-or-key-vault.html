IOptionsMonitor OnChange Never Fires for Env Vars or Key Vault

"IOptionsMonitor reflects live changes" is only true for sources that actually surface a change token. Environment variables and default-configured Azure Key Vault load once at startup — OnChange() never fires for them, no matter how long the process runs.
