How IMemoryCache Expiry Is Actually Enforced — Lazy Checks, Not Timers

The main page explains what the expiration options mean but not when removal actually happens. There is no per-entry timer — expiry is checked on access and by an activity-triggered scan, so untouched expired entries linger in memory.
