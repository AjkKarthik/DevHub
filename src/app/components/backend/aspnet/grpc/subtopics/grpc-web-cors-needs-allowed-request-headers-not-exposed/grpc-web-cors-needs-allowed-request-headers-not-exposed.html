gRPC-Web CORS Needs Allowed Request Headers, Not Just Exposed Ones

The main page's own CORS guidance only exposes response headers to the browser. Without also allowing gRPC-Web's own request headers via WithHeaders, the preflight fails silently — no request ever reaches the server, and there's nothing to log.
