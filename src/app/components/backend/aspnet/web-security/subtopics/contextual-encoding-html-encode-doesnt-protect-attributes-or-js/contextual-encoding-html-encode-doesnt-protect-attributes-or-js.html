Contextual Encoding — HTML Encode Doesn't Protect Attributes or JS

"Encode with HtmlEncoder" is only correct for a text-node sink. An unquoted attribute or an inline <script> block needs a different encoder entirely — HTML entities aren't decoded by the JavaScript parser at all.
