How UseStaticFiles Computes ETag — Why Touching a File Busts the Cache

The main page says ETag and Last-Modified are set "automatically" without saying what they're actually derived from. It's file length and timestamp, not content — so a deploy that resets timestamps busts every client's cache even when nothing changed.
