StartAsync Returns Before ExecuteAsync Actually Completes

The main page's "sequential StartAsync" fact and its "move init to ExecuteAsync" advice are the same mechanism. StartAsync only waits for ExecuteAsync's first genuine yield point — synchronous work before that point blocks host startup exactly like code in StartAsync would.
