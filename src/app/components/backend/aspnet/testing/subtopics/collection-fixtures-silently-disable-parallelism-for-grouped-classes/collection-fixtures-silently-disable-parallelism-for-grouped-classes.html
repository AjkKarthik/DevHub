Collection Fixtures Silently Disable Parallelism for Grouped Classes

The main page mentions parallel test classes and shared collection fixtures as two separate facts. They're the same mechanism — grouping classes into one collection to share a factory is exactly what forces them to run sequentially instead of across every CPU core.
