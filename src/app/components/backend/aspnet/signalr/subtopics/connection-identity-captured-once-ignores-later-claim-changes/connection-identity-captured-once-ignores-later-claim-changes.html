Connection Identity Captured Once — Ignores Later Claim Changes

Unlike an HTTP API where every request re-validates its JWT, a SignalR connection authenticates ONCE at connect time. A token expiring or a role being revoked mid-connection has zero effect until the client actually reconnects.
