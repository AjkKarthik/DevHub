How Groups and Context Persist Across Transient Hub Instances

The Hub object really is thrown away after every call. Context.Items and Groups membership persist because they live on entirely separate objects — a per-connection context and a Singleton-scoped lifetime manager — that each new Hub instance is simply handed a reference to.
