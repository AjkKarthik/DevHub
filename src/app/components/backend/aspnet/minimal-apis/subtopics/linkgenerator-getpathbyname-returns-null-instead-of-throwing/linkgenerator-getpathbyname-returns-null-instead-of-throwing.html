LinkGenerator.GetPathByName Returns Null Instead of Throwing

The main page calls WithName() + LinkGenerator equivalent to a controller's CreatedAtAction. It isn't — CreatedAtAction throws when route values don't match; LinkGenerator returns null silently, producing a 201 response with a missing Location header.
