DB Check Connection Pool Contention Causes Cascading Failure

The main page warns about a DB check on liveness causing a crash-loop. A DB check on readiness has an analogous but distinct risk — it shares the connection pool with real traffic, so it's most likely to fail exactly when removing a pod does the most damage.
