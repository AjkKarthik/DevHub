Degraded Returns 200 by Default — Invisible to Load Balancers

Degraded's whole purpose is early alerting — but it returns the same 200 status code as Healthy, and most load balancers route purely on 2xx vs non-2xx. The signal only reaches whatever actually parses the JSON body.
