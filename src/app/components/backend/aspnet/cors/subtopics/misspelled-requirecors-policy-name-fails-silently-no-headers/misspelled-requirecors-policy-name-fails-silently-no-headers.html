Misspelled RequireCors Policy Name Fails Silently — No Headers

Named CORS policies resolve lazily, per request. A typo in .RequireCors("...") throws no exception at startup or runtime — the endpoint just returns 200 with no Access-Control-Allow-Origin header, invisible to curl, Postman, and body-only tests alike.
