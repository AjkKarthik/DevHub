ApplicationStopping Fires Before In-Flight Requests Finish Draining — Cleanup There Can Race Against Requests Still Being Served

The main topic page describes ApplicationStopping as firing "when shutdown begins" — precise, but easy to misread as "no more requests are being served." It fires at the START of the drain window, not the end, and disposing shared resources there races in-flight requests.
