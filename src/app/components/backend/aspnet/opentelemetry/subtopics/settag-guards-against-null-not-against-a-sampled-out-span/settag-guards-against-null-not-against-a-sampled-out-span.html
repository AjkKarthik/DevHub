SetTag Guards Against Null, Not Against a Sampled-Out Span

The null-conditional operator on activity?.SetTag(...) only guards against an unregistered ActivitySource. A non-null Activity with IsAllDataRequested false still runs — and pays for — any expensive tag computation.
