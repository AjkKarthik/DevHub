Response.OnStarting Callbacks Run in LIFO Order — the Last One Registered Fires First

The main topic page shows one OnStarting callback per example, so the ordering question never arises. With two or more, callbacks fire in LIFO order — the callback registered last (closest to the endpoint) runs first, the reverse of what registration order suggests.
