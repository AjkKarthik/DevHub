Why the Re-Executed Error Endpoint Must Explicitly Restore the Status Code

The main page's own error endpoint passes statusCode: code into Results.Problem() — not decoration. Re-execution only preserves the original status as information to read; forgetting to re-apply it turns a 404 into a silent 200.
