Unmarshal Leaves Absent Fields Unchanged

json.Unmarshal merges into its target rather than resetting it first — a field with no corresponding key in the JSON keeps whatever value the target already had, which makes it a natural fit for partial updates and a real risk when a struct variable is reused across decodes.
