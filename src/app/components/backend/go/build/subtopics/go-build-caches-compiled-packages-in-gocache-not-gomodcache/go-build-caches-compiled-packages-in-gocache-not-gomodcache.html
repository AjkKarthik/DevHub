go build Caches Compiled Packages in GOCACHE, Not GOMODCACHE

The main page's own theory says compiled packages are cached in $GOPATH/pkg/mod/cache — that directory actually holds downloaded dependency source; the build cache lives at a separate location, GOCACHE.
