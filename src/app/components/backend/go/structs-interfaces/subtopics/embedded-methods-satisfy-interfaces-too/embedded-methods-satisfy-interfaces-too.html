Embedded Methods Satisfy Interfaces Too

Go's own spec: promoted methods are genuinely included in the embedding struct's own method set — a struct can satisfy an interface entirely through what it embeds.

Where this fits

The main page's own theory describes embedding as promoting fields and methods "onto" the outer struct without stating whether that counts toward interface satisfaction — this subtopic confirms it does, directly from the spec.
