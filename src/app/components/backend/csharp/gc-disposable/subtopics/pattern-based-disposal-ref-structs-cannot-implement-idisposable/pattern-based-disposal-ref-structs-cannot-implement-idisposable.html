Pattern-Based Disposal: Why using Works on ref structs That Can't Implement IDisposable At All

The main topic page treats using as tied to IDisposable. The compiler actually resolves using via pattern matching on a public Dispose() method — no interface required. See why this matters specifically for ref structs, which are forbidden from implementing any interface.
