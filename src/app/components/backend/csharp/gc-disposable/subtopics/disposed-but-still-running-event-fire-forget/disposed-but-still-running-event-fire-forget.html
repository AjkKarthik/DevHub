Disposed but Still Running: Why an Event Handler or Fire-and-Forget Task Can Outlive Dispose()

The main topic page's _disposed guard protects direct callers. It does nothing to stop an event publisher's stored delegate or an already-running fire-and-forget task from touching the object after Dispose() has run.
