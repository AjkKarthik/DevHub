Extension Methods on Structs: Using this in T to Avoid Copying the Receiver

Every extension method example on the main topic uses a plain by-value receiver — for a large struct, this copies it on every call. This subtopic covers this in T, the C# 7.2 syntax that passes the receiver by readonly reference instead.
