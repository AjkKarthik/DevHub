How rollForward Actually Picks an SDK Version: The Feature-Band Matching Algorithm Behind latestMinor

The main topic page's global.json table lists rollForward values as outcomes. Here's the actual algorithm: SDK versions encode a feature band digit, and latestMinor specifically means finding the highest installed feature band, then the highest patch within it.
