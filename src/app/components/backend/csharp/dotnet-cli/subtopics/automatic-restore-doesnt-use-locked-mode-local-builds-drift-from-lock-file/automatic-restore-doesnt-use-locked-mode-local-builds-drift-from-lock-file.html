dotnet build's Automatic Restore Doesn't Use --locked-mode — Local Builds Can Silently Drift From the Committed Lock File

The main topic page notes that restore "runs automatically before build." That automatic restore is a different, more permissive operation than CI's --locked-mode restore — it can silently rewrite packages.lock.json as a side effect of routine local development.
