Records Used as Dictionary Keys Can Silently Break When a Reference-Typed Property Is Mutated After Insertion

Init-only properties feel immutable, but they only prevent reassignment — if a record property is a reference to a genuinely mutable object, mutating that object after insertion silently changes the record's effective hash code, breaking dictionary lookups.
