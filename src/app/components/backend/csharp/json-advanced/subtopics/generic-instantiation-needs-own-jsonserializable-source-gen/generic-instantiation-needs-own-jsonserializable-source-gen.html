Why Every Generic Instantiation Needs Its Own [JsonSerializable]: PagedResult<Product> Is a Distinct Type to the Source Generator

Reflection-based serialization handles any generic instantiation automatically at runtime. Source generation does not — PagedResult<Product> and PagedResult<Order> are unrelated types to the generator, and a missing registration only fails at runtime, often only in a Native AOT build.
