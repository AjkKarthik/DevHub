A Clean IsAotCompatible Build Can Still Fail dotnet publish -p:PublishAot=true — Trim Analysis and Native Compilation Check Different Things

The main topic page recommends checking a package's IsAotCompatible metadata and running trim analysis in CI. Both are good advice — but trim analysis and the actual ILC native compiler check genuinely different properties, and a package can pass one while failing the other.
