Classes, Interfaces & Records

The three main ways to define types in C# — pick the right one for the job.

class — use for services, repositories, entities with identity and mutable state.
interface — use to define capabilities. Classes can implement many interfaces.
record — use for DTOs, API responses, and value objects. Immutable by default.
abstract class — use when you need shared implementation with enforced overrides.
