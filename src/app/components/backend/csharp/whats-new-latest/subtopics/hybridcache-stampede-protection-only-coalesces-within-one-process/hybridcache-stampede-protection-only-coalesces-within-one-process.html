HybridCache's Stampede Protection Only Coalesces Callers Within One Process — Distributed Races Still Happen Across App Instances

The main topic page describes stampede protection without specifying its scope. In-process coalescing genuinely prevents duplicate factory calls within one instance — but each app instance in a scaled-out deployment can independently invoke its own factory call at the same moment.
