Classes, Properties & Inheritance

Auto-properties, access modifiers, virtual/override, abstract classes and interfaces — the complete OOP toolkit.

virtual + override Mark the base method virtual and the derived version override. The runtime dispatches to the correct type at runtime — that's polymorphism.
abstract An abstract class cannot be instantiated. Abstract members have no body — every derived class must provide one. Perfect for template-method patterns.
sealed Prevents further derivation. Use it when subclassing would break the class's invariants, or to enable JIT de-virtualisation.
interface Pure contract — no fields or constructor. A class can implement many interfaces; enables clean dependency injection and testability.
