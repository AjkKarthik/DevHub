A Primary Constructor Parameter Referenced Anywhere in the Body Gets Captured as a Field for the Object's Entire Lifetime

The main topic page's DI example makes primary constructors look like pure syntax sugar. A rarely-called diagnostic method referencing a parameter is enough to silently capture it as a field, keeping whatever it references alive for as long as the object lives.
