string.Create and Span<char>: Building a String Once, Allocation-Free, Without a StringBuilder Layer

StringBuilder is O(n) but still involves a buffer plus a final copy on ToString(). When the final length is known upfront, string.Create writes characters directly into the destination string's own memory — one allocation, zero copies.
