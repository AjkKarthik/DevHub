stackalloc Inside a Loop Never Frees Between Iterations — Stack Space Accumulates Until the Method Returns

"No GC involved" also means no automatic per-iteration cleanup. A fresh stackalloc call on every loop pass keeps accumulating on the same stack frame until the whole method returns — risking an uncatchable StackOverflowException.
