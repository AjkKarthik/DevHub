Testing Default Interface Method Resolution: Interface-Typed vs Class-Typed References

The main topic's own Common Mistake shows default methods are only reachable through an interface-typed reference — a compile-time fact, not a runtime one. This subtopic shows what genuinely can (and can't) be tested about it.
