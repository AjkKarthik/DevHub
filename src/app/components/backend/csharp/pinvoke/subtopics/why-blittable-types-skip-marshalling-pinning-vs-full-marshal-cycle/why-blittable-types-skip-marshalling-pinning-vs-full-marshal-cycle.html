Why Blittable Types Skip Marshalling Entirely: Pinning and Direct Pointer Passing vs the Full Marshal-Copy-Convert Cycle

The main topic page's Q&A defines blittable versus non-blittable types. Here's the mechanism: a blittable type's managed and native layouts are byte-identical, so the GC only needs to pin it in place — a non-blittable type needs an entirely separate, converted buffer built from scratch.
