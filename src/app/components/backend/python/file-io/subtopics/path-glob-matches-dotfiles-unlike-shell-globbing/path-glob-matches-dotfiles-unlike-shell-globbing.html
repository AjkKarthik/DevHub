Path.glob() Matches Dotfiles, Unlike Shell Globbing

Pathlib's own docs confirm dotfiles "are not special" to Path.glob()/.rglob() — the reverse of shell wildcards and the standalone glob module, and a genuine security-relevant gap to guard against.
