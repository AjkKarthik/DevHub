MSSQL TABLESAMPLE ROWS Can Return Far Fewer Rows Than Requested

The main page implies PostgreSQL's page-based sampling is the "approximate" one — MSSQL's TABLESAMPLE (N ROWS) is also page-based, and can return zero rows on small tables.
