Correcting the ts_rank "0.0 to 1.0" Fixed Range Claim

Unlike MSSQL's genuinely-bounded 0-1000 RANK, PostgreSQL's default ts_rank has no fixed upper bound — a document with enough term matches can score well above 1.0.
