ZRANGEBYLEX Is Deprecated — Use ZRANGE ... BYLEX

The main page's QnA presents ZRANGEBYLEX as a current command — verified against Redis's own docs, it has been deprecated since Redis 6.2.0 in favor of the unified ZRANGE ... BYLEX, the same replacement pattern already used for ZRANGEBYSCORE.
