MULTI/EXEC Real Atomicity: Isolation, Not Rollback

The main page's own quiz calls pipelining "not atomic, unlike MULTI/EXEC" — accurate, but easy to misread. MULTI/EXEC never rolls back a runtime error in one of its queued commands; its real guarantee is isolation from other clients.
