Since Redis 7.0, Scripts No Longer Need to Be Deterministic

The main page's QnA listed "deterministic required" as a standing Lua limitation. It described verbatim replication — removed entirely in Redis 7.0. Under today's effects replication, math.random, TIME, and SRANDMEMBER are all fair game.
