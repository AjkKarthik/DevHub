RESP3 Removes the Subscribe-Mode Restriction Entirely

The main page states flatly that Pub/Sub always needs two connections. Verified against Redis's own docs: that's a RESP2-specific limitation — under RESP3, one connection can subscribe and run regular commands at the same time.
