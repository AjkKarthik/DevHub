Federation v2 Doesn’t Replace the Gateway

The main page's own theory claimed Federation v2 "removes the gateway in favor of the Apollo Router." Verified against Apollo's own docs that this has the relationship backwards -- Gateway 2.0+ works fine with Federation v2, and Router is a separate, newer runtime, not a replacement.
