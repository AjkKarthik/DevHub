Correlated vs. Uncorrelated $lookup Subqueries

The main page's own theory section originally called the let/pipeline form "uncorrelated" — verified against MongoDB's own documentation that this is backwards: the let/pipeline form is exactly what MongoDB calls correlated.

Where this fits

Getting this terminology right matters beyond a vocabulary quiz — recognizing whether a sub-pipeline is correlated or uncorrelated tells you whether MongoDB can potentially cache and reuse the sub-pipeline's result across documents, which is a real, checkable performance lever on a pipeline with many joined documents.
