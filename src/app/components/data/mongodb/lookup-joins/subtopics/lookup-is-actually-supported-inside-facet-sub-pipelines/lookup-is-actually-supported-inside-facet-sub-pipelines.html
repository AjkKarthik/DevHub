$lookup Is Actually Supported Inside $facet Sub-Pipelines

The main page's own QnA on $lookup limits originally claimed $lookup could not run inside a $facet sub-pipeline — verified against MongoDB's own documented exceptions list that this is wrong, and $lookup works fine inside $facet.

Where this fits

Correcting this claim matters for real report/dashboard queries — a single $facet call can now confidently combine multiple independently-joined, independently-filtered views of the same data in one round trip, instead of assuming a separate query is required for every branch that needs a $lookup.
