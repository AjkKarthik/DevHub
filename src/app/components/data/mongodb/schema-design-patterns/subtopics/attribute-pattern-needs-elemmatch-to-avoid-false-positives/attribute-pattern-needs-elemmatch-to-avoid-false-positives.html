Where this fits

The Attribute Pattern is a genuinely different tool from the Polymorphic Pattern the main page already covers in a codeTab — polymorphism handles different DOCUMENT SHAPES in one collection, while the Attribute Pattern handles different SEARCHABLE FIELDS within otherwise similar documents, and the two are commonly combined (a polymorphic products collection where each type's own extra fields live in its own specs array).
