reIndex Never Got the Non-Blocking Hybrid Build Fix

The main page's own QnA claimed "MongoDB 4.4+: background reindex supported (non-blocking)" — verified against MongoDB's own documentation that reIndex() has never supported a non-blocking mode, on any version.
