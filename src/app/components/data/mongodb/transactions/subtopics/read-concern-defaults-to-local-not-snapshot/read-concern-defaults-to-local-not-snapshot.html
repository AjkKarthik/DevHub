Read Concern Defaults to Local, Not Snapshot

The main page's own QnA on read concern "snapshot" called it the default for a transaction — verified against MongoDB's own documentation that the real default, if nothing is set, is "local".

Where this fits

This corrects the main page's own QnA directly, and sets up the distinction the rest of this topic's subtopics build on: the read concern LEVEL a transaction runs under is one setting (with its own precedence chain), while snapshot isolation is a completely separate, always-on guarantee every transaction gets regardless.
