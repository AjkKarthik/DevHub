The Oplog Default Has a 990MB Floor

The main page's own QnA described the default oplog size as "5% of disk or 50GB, whichever is smaller" — correct on the upper side, but missing the 990MB minimum floor MongoDB's own documentation also specifies.

Where this fits

This tightens the main page's own oplog-size description, and connects directly to a related fact already covered elsewhere in this hub: oplogMinRetentionHours (a separate, opt-in setting) defaults to 0, while THIS floor (990MB) is baked into the automatic size formula itself with no configuration needed.
