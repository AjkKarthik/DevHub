rel="noopener" Genuinely Nulls window.opener

Without noopener, a target="_blank" popup gets a real, working reference back to the page that opened it. Adding noopener doesn't hide that reference — it makes it genuinely null.

See it run

Two buttons open a same-origin popup — one without noopener, one with it. Each popup checks its OWN window.opener and reports the result back here.
