An Empty sandbox Blocks Script Execution Entirely

Sandbox tokens are additive and independent — allow-scripts controls whether a frame's own code runs; allow-same-origin separately controls whether the parent can read the frame afterward.

See it run

Two identical srcdoc iframes, both readable by the parent via allow-same-origin, differ only in whether they also grant allow-scripts. Watch which one's marker div actually gets mutated.

Where this fits

Sandboxing is a security boundary, entirely orthogonal to the loading-timing and srcset-selection mechanics covered in the previous two subtopics — an iframe can be perfectly performant and still be a serious security risk if sandboxed incorrectly.
