sizes, Not Media Queries, Picks the srcset Candidate

srcset only lists candidate files. The sizes attribute is the browser's only signal for how wide the image actually renders — get it wrong and even a perfectly correct srcset over-fetches.

See it run

Two images render at the identical 300px CSS width. One has an accurate sizes="300px"; the other lies with sizes="1200px". Inspect currentSrc to see which candidate the browser actually fetched for each.

Where this fits

This is a separate mechanism from the timing question the previous subtopic covers (eager vs lazy) — sizes controls WHICH file loads, loading controls WHEN it loads. Neither has anything to do with the iframe sandbox restrictions in the next subtopic. Return to the Media Elements overview for the full picture.
