loading="lazy" Defers the Fetch Until Near the Viewport

An eager image starts downloading the instant the parser sees it, no matter how far down the page it sits. A lazy image withholds the network request entirely until it nears the viewport.

See it run

Two images sit 3000px below the fold — one loading="eager", one loading="lazy". Check naturalWidth immediately on page load, then again after scrolling the lazy one into view.

Where this fits

Knowing exactly when the fetch happens explains why sizes matters just as much as srcset for controlling what gets downloaded — see the next subtopic — and why sandboxing an untrusted embed (the third subtopic) is a completely separate, orthogonal concern from loading performance.
