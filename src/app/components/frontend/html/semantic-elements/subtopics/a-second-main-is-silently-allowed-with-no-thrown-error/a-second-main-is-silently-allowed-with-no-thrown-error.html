A Second main Element Is Silently Allowed, With No Thrown Error

"Exactly one <main> per page" is a content-model rule, not a parsing rule — the browser renders two of them with zero errors, warnings, or visible signs anything is wrong.

See it run

A document with two <main> elements loads and renders completely normally. Check document.querySelectorAll('main').length directly, then see a small "audit" function that catches what the browser itself won't flag.
