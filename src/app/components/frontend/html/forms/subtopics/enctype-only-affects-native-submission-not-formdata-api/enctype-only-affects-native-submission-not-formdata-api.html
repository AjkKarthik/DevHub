enctype Only Affects Native Submission, Not the FormData API

new FormData(formElement) reads a file input's real File object straight from the DOM — the form's enctype attribute is never consulted in this path at all.

See it run

A form with NO enctype attribute (defaulting to the "loses file content" value) still produces a FormData object whose file entry has its full, real content intact. Confirm it, then see why fetch() doesn't need enctype either.
