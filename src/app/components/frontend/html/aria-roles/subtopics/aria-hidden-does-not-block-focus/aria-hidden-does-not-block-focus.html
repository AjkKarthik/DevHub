aria-hidden Does Not Block Focus

A button inside an aria-hidden container is invisible to screen readers but still fully reachable via Tab — a real, well-documented focus trap.

See it run

Focus a button hidden inside an aria-hidden="true" container and confirm document.activeElement reaches it anyway — proving the attribute never touches focusability.

Where this fits
