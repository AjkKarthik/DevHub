No Native Keyboard-to-dragstart Mapping Exists

Unlike a button's real (if untestable) Enter activation, there is no native keyboard path to dragstart at all — an absence that's directly provable.

See it run

Dispatch Enter and Space at a focused draggable element and confirm dragstart never fires — then confirm a manually-added keydown handler CAN detect the same keys, showing where the gap must be filled.
