clearData Selectively Removes One Type

clearData("text/plain") removes only that one MIME type — every other type set on the same DataTransfer object survives, provable directly.

See it run

Set two MIME types, clear just one, and confirm the other survives — then call clearData() with no arguments to see the total-wipe form.
