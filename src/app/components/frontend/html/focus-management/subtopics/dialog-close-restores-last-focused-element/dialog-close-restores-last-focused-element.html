dialog close() Restores the Last-Focused Element

Native <dialog> genuinely restores focus on close — but to whatever was focused at showModal() time, not necessarily the button the user thinks of as "the trigger".

See it run

An intervening decoy focus call right before showModal() proves the browser's restoration mechanism is real — and shows exactly what it actually snapshots.

Where this fits

This closes out three focus-management gotchas: tabindex used correctly to shape widget behavior (roving tabindex), tabindex misused to silently reorder the whole page (positive values), and a native mechanism that's real and automatic but easy to misjudge exactly WHAT it captures.
