QuotaExceededError Is a Real, Catchable Exception

Running localStorage out of room doesn't silently fail — setItem() throws a real DOMException on the exact call that pushes it over quota.

See it run

Write growing chunks to localStorage in a loop until quota is hit, catching the real DOMException and counting exactly how many writes succeeded first.

Where this fits

This closes out three storage gotchas that all hinge on the same question — silent vs. loud failure. Storing an object fails silently (wrong data, no error); a same-tab storage listener fails silently (no error, just never runs); running out of quota fails loudly (a real, catchable exception).
