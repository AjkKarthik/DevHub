localStorage Only Stores Strings, Not Objects

Passing an object to setItem() never throws — it silently stores the literal text "[object Object]" instead.

See it run

Compare storing an object directly against the JSON.stringify()/JSON.parse() pattern — one silently loses the data, the other round-trips it faithfully.

Where this fits

This is a silent-failure gotcha specific to WRITING data. Next, see a silent-omission gotcha specific to the storage event fired when data is written — it never reaches the tab that made the change.
