Nested header Loses Implicit Banner Role

A <header> only gets the implicit "banner" landmark role at the document's top level — nesting it inside article/aside/main/nav/section removes it.

See it run

A top-level header and an article-nested header get checked against the exact structural condition the spec uses to decide the implicit banner role.

Where this fits

This closes out three landmark gotchas the browser itself won't warn you about: an unenforced one-main rule, unlabeled navs that are indistinguishable by name, and a header's landmark role silently depending on its nesting position. Return to the Landmark Elements overview for the full picture.
