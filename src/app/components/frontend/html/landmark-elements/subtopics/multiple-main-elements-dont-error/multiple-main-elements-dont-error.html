Multiple main Elements Don't Error

"Only one <main> per document" is a spec convention for accessibility tooling to catch — the parser accepts as many as you write.

See it run

A document with two <main> elements parses without a single warning — querySelectorAll('main').length reports 2, and the fix is the hidden attribute, not deleting one.
