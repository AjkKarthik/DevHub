aria-hidden Removes From the a11y Tree, Not the Tab Order

aria-hidden="true" hides an element from screen readers — it does nothing to tabIndex or .focus(). A keyboard user can land on a control a screen reader user is told doesn't exist.

See it run

One normal button, one with aria-hidden="true". Compare their tabIndex and confirm both genuinely accept keyboard focus.
