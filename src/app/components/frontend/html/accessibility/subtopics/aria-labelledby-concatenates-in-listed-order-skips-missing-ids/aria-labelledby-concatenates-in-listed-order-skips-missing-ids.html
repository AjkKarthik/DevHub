aria-labelledby Concatenates in Listed Order, Skips Missing ids

Multiple space-separated ids in aria-labelledby are read in the order WRITTEN, not the order the elements appear in the DOM — and a missing id is silently dropped.

See it run

A button's aria-labelledby lists ids in one order, while the referenced elements sit in a different order in the DOM — and one id doesn't exist at all. Compute the true accessible name and compare it against a naive DOM-order guess.
