A Native button Translates Enter/Space, div role="button" Does Not

A real <button> automatically synthesizes a click event from Enter or Space. A div with role="button" and only a click handler stays completely silent on the keyboard.

Neither control has a keydown listener — only a click listener, on both. Tab to each and press Enter to see which one actually responds.
