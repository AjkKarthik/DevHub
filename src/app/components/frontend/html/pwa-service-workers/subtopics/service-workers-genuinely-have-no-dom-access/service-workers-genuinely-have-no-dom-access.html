Service Workers Genuinely Have No DOM Access

document and window aren't blocked from a service worker — they're simply never defined in its global scope. typeof proves it with no error at all.

See it run

A service worker checks typeof document/typeof window from inside its own script and reports the result back to the page via postMessage.
