Unused CSS Selectors Stay in the CSSOM Until You Remove Them

A rule for a class matching zero elements was still fully parsed and stored in the live CSSOM — the browser has no mechanism to skip or discard CSS that nothing on the page currently uses.

Inject a CSS rule for a class used nowhere in the document, then check whether the browser stores it anyway.
