Domain Sharding Defeats HTTP/2 Connection Coalescing

Sharding solved the HTTP/1.1 6-connections-per-origin limit — a limit HTTP/2 multiplexing removes entirely. Keeping it after migrating forces redundant DNS/TCP/TLS handshakes for nothing.

Code Examples

Sharded hostnames force separate connections on HTTP/2; consolidating to one origin lets multiplexing handle everything — and DevTools' Connection ID column confirms whether coalescing actually happened.
