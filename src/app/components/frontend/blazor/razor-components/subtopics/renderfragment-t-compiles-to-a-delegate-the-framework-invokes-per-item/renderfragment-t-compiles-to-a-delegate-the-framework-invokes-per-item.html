RenderFragment<T> Compiles to a Delegate the Framework Invokes Per Item

RenderFragment<T> is not pre-rendered HTML the parent hands over once — it's a Func<T, RenderFragment> the child invokes once per item, meaning the parent's template code genuinely re-executes every time it's called.
