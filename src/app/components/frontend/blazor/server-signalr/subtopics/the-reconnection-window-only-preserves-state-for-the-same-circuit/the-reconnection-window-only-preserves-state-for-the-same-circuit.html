The Reconnection Window Only Preserves State for the Same Circuit

A disconnected circuit is held paused in server memory for DisconnectedCircuitRetentionPeriod, waiting for the exact same session to reconnect — if that window expires, the state is genuinely, permanently gone, not recoverable another way.
