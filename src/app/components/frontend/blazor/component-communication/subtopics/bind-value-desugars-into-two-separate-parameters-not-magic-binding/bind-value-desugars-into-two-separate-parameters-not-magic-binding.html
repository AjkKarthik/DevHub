bind-Value Desugars Into Two Separate Parameters, Not Magic Binding

@bind-Value is pure compile-time text expansion into two ordinary attributes (Value and ValueChanged) based on an exact name match — no runtime reflection, no flexible matching, and a mismatched name fails completely silently.
