Cross-Tab Sync Needs the Browser's Own StorageEvent, Not Blazor

Every browser tab is a genuinely separate circuit or app instance with no shared C# memory — the only bridge between tabs is the browser's own standard 'storage' event, which fires only in OTHER tabs, never the one that made the change.
