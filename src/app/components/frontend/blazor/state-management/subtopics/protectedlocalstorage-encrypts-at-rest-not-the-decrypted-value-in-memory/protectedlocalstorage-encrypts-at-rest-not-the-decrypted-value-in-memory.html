ProtectedLocalStorage Encrypts at Rest, Not the Decrypted Value in Memory

The encryption only protects a value while it sits in browser storage as ciphertext — the moment your own code calls GetAsync, the decrypted plaintext is fully exposed in the page's own memory like any other data.
