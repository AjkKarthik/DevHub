Hybrid Has No Circuit — State Lives in the Native Process, Not a Connection

A network interruption has zero effect on a Hybrid app's own UI state, unlike Blazor Server — the real state-loss triggers are native process lifecycle events instead: the app being force-quit or terminated by the OS under memory pressure.
