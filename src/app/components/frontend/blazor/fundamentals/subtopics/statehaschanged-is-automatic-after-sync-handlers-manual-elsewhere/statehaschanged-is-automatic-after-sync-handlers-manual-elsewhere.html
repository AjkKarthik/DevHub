StateHasChanged() Is Automatic After Sync Handlers, Manual Elsewhere

Blazor auto-renders after any code path it dispatched itself — event handlers, lifecycle methods. Background timers, injected-service event subscriptions, and thread-pool callbacks run outside that path and need an explicit StateHasChanged() call.
