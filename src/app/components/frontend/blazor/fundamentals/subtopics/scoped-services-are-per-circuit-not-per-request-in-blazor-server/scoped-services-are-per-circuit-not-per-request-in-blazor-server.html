Scoped Services Are Per-Circuit, Not Per-Request, in Blazor Server

Blazor Server has no HTTP request/response cycle for most of its lifetime — Scoped maps to the long-lived SignalR circuit instead, meaning one instance per browser tab session, shared across every component and event for that whole session.
