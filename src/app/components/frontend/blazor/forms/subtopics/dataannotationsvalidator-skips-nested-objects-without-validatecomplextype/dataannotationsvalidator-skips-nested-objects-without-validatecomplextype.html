DataAnnotationsValidator Skips Nested Objects Without ValidateComplexType

The default DataAnnotationsValidator only checks the root model's own properties — a nested Address object's [Required] attributes are silently never evaluated unless both [ValidateComplexType] and ObjectGraphDataAnnotationsValidator are added together.
