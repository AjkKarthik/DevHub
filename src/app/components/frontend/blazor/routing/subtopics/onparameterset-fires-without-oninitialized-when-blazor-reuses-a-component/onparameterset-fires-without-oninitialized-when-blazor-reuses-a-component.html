OnParametersSet Fires Without OnInitialized When Blazor Reuses a Component

Navigating between two routes handled by the same component type reuses that instance rather than recreating it — OnInitialized correctly runs only once, which is exactly why route-parameter-dependent loading belongs in OnParametersSet instead.
