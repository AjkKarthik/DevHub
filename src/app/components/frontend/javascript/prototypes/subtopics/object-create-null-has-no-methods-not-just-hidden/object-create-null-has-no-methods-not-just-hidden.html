Testing That Object.create(null) Genuinely Has No Methods, Not Just Hidden From Enumeration

The main page's own demo sets toString before testing it — this tests the genuinely empty case, calling toString() on an object that never had it set, to confirm it's really absent.

A plain {} object and an Object.create(null) object, both tested for typeof .toString and an actual call to .toString().
