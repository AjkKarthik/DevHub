curry()'s fn.length Check Miscounts Default and Rest Parameters

Function.prototype.length only counts required parameters before the first default or rest parameter — curry()'s fn.length check silently breaks on either.

See it run

The main page's own curry() utility, unmodified, is applied to a function with a default parameter and one with a rest parameter. Watch it invoke each too early, compared against a plain-parameter function where it works correctly.
