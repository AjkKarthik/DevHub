Object.freeze() Is Only Shallow — Nested Objects Stay Mutable

Object.freeze() protects only the object it's called on directly — any nested object stored inside its properties remains exactly as mutable as before.

See it run

A frozen state object rejects a top-level reassignment but silently accepts a nested mutation two levels deep. Compare against a recursive deepFreeze() that closes the gap.
