innerHTML += Reparses the Whole Container and Destroys Child Listeners

innerHTML += isn't an efficient append — it serializes, reparses, and rebuilds every existing child node from scratch, silently detaching every listener along the way.

See it run

A button with a click listener is clicked, some HTML is appended via innerHTML +=, and the same button is clicked again. Watch whether the listener still fires — and whether the button is even the same node object.
