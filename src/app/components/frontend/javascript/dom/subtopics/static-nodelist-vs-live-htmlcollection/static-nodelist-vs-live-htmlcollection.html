querySelectorAll Is Static, getElementsByClassName Is Live

A NodeList from querySelectorAll is a frozen snapshot — an HTMLCollection from getElementsByClassName continuously reflects the current DOM, with no re-query needed.

See it run

Both a static NodeList and a live HTMLCollection are captured before a new matching element is added to the DOM. Compare their lengths afterward — then see the practical danger of iterating a live collection while mutating the DOM mid-loop.
