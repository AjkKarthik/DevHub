Breaking a for...of Loop Triggers generator.return() and Runs finally

A break statement doesn't just abandon a generator — for...of automatically calls .return() on it, immediately running any enclosing finally block.

See it run

A generator wrapping a "resource" with try/finally is consumed three ways — an early break, a manual .return() call, and an exception thrown from the loop body. Watch exactly when the cleanup log fires in each case.
