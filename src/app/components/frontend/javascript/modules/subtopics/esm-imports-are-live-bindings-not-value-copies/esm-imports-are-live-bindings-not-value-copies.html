ESM Imports Are Live Bindings, Not Value Copies

An imported binding stays connected to the exporting module's own variable — when it changes there, every importer sees the new value automatically, with no re-import needed.

See it run

A real two-file ESM setup — counter.ts exports a mutable count, index.ts imports it and watches it update after each increment() call, contrasted with a plain value-copy destructure.
