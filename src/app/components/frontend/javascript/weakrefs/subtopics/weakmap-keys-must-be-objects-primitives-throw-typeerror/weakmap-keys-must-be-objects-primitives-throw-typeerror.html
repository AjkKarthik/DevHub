WeakMap Keys Must Be Objects — Primitives Throw a TypeError

Only objects — and, since ES2023, unregistered Symbol() values — can be WeakMap keys, since the GC needs genuine identity to track for automatic cleanup.

See it run

A string, number, boolean, plain Symbol(), registered Symbol.for(), and plain object are each attempted as a WeakMap key. Watch which ones throw and which succeed.
