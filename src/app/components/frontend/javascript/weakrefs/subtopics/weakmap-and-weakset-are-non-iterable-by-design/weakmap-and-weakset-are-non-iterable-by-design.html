WeakMap and WeakSet Are Non-Iterable by Design

Iteration would make garbage collection timing observable — a permanent, deliberate spec restriction, not a missing feature.

See it run

Every common way of inspecting a collection's contents — .size, for...of, spread, Array.from, Object.keys — is tried against a WeakMap. Compare which ones throw, which return nothing useful, and which work fine on a regular Map.
