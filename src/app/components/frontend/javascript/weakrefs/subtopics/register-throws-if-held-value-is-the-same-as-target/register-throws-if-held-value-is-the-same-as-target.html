register() Throws if heldValue Is the Same as target

heldValue is held with a strong reference — if it could be target itself, that reference would permanently prevent target from ever being collected.

See it run

A registration with heldValue set to the same object as target is attempted, then compared against a correctly-shaped registration and the separate unregisterToken parameter.
