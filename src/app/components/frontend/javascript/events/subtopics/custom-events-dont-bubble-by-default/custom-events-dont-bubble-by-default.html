Custom Events Don't Bubble by Default

Unlike most native DOM events, CustomEvent defaults bubbles to false — a parent listener silently never fires unless you opt in explicitly.

See it run

The same parent listens for two custom events dispatched from an identical child — one without bubbles: true, one with it — plus a native click for contrast. Watch which ones the parent actually hears.
