A Response Body Can Only Be Consumed Once

A Response body is a ReadableStream — a second body-reading call throws once the first has drained it. res.clone() only helps if called before the first read.

See it run

Three attempts read a fake JSON response's body twice — once with no cloning (fails), once cloning before the first read (works), and once cloning after the first read (still fails). Compare the outcomes.
