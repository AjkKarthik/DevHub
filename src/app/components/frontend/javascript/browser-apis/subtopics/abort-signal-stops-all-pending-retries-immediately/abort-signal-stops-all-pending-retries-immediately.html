AbortController Stops Every Pending Retry Immediately

Threading the same signal through every retry attempt means one .abort() call cancels the in-flight request AND prevents every future attempt in the loop from ever starting.

See it run

A simulated retry loop allows up to 10 attempts, but abort() fires partway through. Watch the attempt counter to confirm the loop genuinely stops early instead of running to completion.
