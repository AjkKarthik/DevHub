fetch() Resolves on 4xx/5xx — It Never Rejects for HTTP Errors

Getting any response back — even a 404 or 500 — counts as success from fetch()'s own perspective. Only a true network failure makes the promise reject.

See it run

A real fetch against a genuine 404 URL resolves without throwing. Compare the "wrong" pattern (skipping response.ok) against the "right" pattern, then contrast both with a true network-level failure.
