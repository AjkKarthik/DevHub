AggregateError Packages Every Promise.any() Rejection, Not Just the First

When every promise in a Promise.any() call rejects, the thrown AggregateError's .errors array preserves every individual failure reason — unlike Promise.all(), which discards all but the first.

Three checks all fail. Compare what Promise.any()'s AggregateError.errors preserves against what Promise.all()'s single caught error loses — then see the same pattern used manually for multi-field validation.
