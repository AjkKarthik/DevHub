finally's return Silently Overrides the catch Block's Return Value

A return (or throw) inside finally doesn't run alongside try/catch's own decision — it completely replaces it, with zero warning.

See it run

A broken version (finally has its own return) and a fixed version (finally only does cleanup) run side by side, plus a third example showing the same override applies to thrown errors, not just return values.
