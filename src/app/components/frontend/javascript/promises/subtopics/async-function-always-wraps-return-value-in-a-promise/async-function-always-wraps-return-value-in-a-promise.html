async Functions Always Wrap Their Return Value in a Promise

The async keyword changes a function's return type unconditionally — even a function with zero real asynchronous work still returns a Promise, never the raw value.

See it run

Two functions with the identical body — one plain, one async — are called three different ways. Watch how typeof and simple arithmetic behave differently depending on whether the Promise is unwrapped.
