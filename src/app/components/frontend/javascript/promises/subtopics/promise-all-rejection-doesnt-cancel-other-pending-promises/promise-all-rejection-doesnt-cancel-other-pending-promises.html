Promise.all Rejection Doesn't Cancel Other Pending Promises

When one promise in a Promise.all array rejects, the call rejects immediately — but the other promises keep running to completion in the background, with their side effects still happening.

See it run

This demo starts three async tasks: one fails fast, two succeed slowly with a logged side effect when they finish. Watch the order the console logs appear in — the side effects from the "cancelled" tasks show up well after the catch block already ran.
