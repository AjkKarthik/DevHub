Forgetting return in .then() Breaks the Chained Value

A .then() callback's return value becomes the next step's input — leave off return and every following .then() silently receives undefined instead.

See it run

Two identical chains run side by side — one with a missing return, one fixed. Compare the console output step by step to see exactly where the real value gets lost.
