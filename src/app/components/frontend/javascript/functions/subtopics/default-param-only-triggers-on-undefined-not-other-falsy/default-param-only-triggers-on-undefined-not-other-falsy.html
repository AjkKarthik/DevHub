Testing That a Default Parameter Only Triggers on undefined, Not null, Zero, False, or Empty String

Mistake #3 only tests null — this runs 6 different inputs to confirm the ONE trigger condition against the four falsy values that don't count.

See it run

One default-parameter function, called with no argument, undefined, null, 0, false, and "".

Where this fits

This is the narrowest of JavaScript's three "defaulting" mechanisms (||, ??, default parameters) made concrete. The final subtopic returns to this-binding, checking whether new can override even a function that was already explicitly bound.
