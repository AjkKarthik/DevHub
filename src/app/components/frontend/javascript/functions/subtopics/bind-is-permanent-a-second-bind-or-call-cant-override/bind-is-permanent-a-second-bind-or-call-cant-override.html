Testing That bind() Is Permanent — a Later call(), apply(), or Second bind() Can't Override It

The QnA calls bind() "permanently bound" — this tests whether that word is literal by trying to override it three different ways after the fact.

See it run

A function bound to objA, then tested against .call(objB), .apply(objB), and a second .bind(objB) call.
