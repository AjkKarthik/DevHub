Testing That Narrowing Survives an Unrelated Function Call

The main page's Q&A says TypeScript "does not track narrowing across regular function calls" — but an unrelated call that never touches the narrowed variable doesn't actually invalidate it.

See it run

Narrow a parameter, call a completely unrelated function, and confirm the narrowing survives — then compare against the genuine exception: a nested closure capturing the same variable.

Where this fits

This refines the main page's own control flow analysis section — narrowing loss isn't about "calling a function" in general, it's specifically about closures capturing the narrowed variable for possibly-deferred execution.
