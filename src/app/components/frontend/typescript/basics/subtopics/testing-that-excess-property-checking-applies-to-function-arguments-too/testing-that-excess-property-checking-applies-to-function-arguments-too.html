Testing That Excess Property Checking Applies to Function Arguments Too

The main page's excess-property example is framed around variable assignment — but the same check fires just as strictly when a fresh object literal is passed directly as a function argument.

See it run

Uncomment each marked line one at a time and watch the editor flag the exact same kind of error whether the fresh object literal appears in an assignment or a function call.

Where this fits

This is the same structural-typing system the main page introduces — excess property checking is simply the one place TypeScript deliberately tightens an otherwise permissive structural check, specifically to catch typos. Knowing it fires at call sites, not just assignments, means you can rely on it catching a typo'd argument the same way it catches a typo'd variable.
