Testing That TypeScript private Is Still Included in JSON.stringify

The main page's Common Mistake shows one bypass — an explicit "as any" cast. This tests a bypass that needs no cast at all: ordinary JSON.stringify.

See it run

Serialize the same shape twice — once with TypeScript's private, once with JavaScript's # — and compare what actually ends up in the JSON.

Where this fits

This extends the main page's own Common Mistake #1 to the everyday code path (serialization) most likely to actually leak private data, without requiring any explicit cast.
