Testing That Direction[42] Returns Undefined, Not a Name

Numeric enums are "open" (any number is assignable) AND generate a reverse mapping — so does indexing with an out-of-range number give you a name back? It doesn't.

See it run

Assign an out-of-range number to a numeric enum variable (TypeScript allows it), then reverse-map it — and check whether a bitwise-flag combination fares any better.

Where this fits

This refines the main page's "reverse mapping" and "open type" claims from two separate sections — combining them shows the reverse mapping is narrower than either claim alone suggests.
