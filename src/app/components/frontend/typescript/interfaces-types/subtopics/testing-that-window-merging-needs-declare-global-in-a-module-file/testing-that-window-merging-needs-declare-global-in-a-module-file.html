Testing That Window Merging Needs declare global in a Module File

The main page's Window augmentation example only merges globally in a script file with no top-level import/export — almost every real TypeScript file is a module, and needs declare global instead.

See it run

Run the main page's exact example inside a module file (one with a top-level export), then compare against the same code wrapped in declare global.

Where this fits

This is the same declaration merging the main page introduces — the missing piece is that merging with a truly GLOBAL type (as opposed to two interfaces merging within the same module) has an extra precondition the main page's example quietly assumes but never states.
