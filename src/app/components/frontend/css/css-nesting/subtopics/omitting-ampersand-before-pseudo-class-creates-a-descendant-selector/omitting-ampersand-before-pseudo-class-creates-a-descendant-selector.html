Omitting & Before a Pseudo-Class Creates a Descendant Selector

.card { :hover { } } isn't .card:hover — it's .card :hover, with a space, matching any hovered descendant instead of the card itself.

See it run

Read the browser's own parsed CSSOM to confirm the missing & becomes an explicit descendant-selector space.
