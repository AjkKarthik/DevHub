sticky Without an Offset Behaves Like static

A sticky element with no top/bottom offset scrolls completely away with its container — measurably identical to position: static.

See it run

Scroll a container 300px and measure a sticky-but-offset-less element's position relative to it — it moves exactly as far as ordinary content would.

Where this fits

This closes out three positioning gotchas that share one theme — a positioning feature silently doing nothing when a specific prerequisite is missing, with no error to flag it. Return to the CSS Positioning & Stacking overview for the full picture.
