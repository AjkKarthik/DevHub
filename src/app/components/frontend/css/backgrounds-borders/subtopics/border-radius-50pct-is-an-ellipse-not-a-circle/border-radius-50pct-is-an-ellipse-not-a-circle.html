border-radius: 50% Is an Ellipse, Not a Circle

Percentage border-radius resolves against width and height independently — only a square element gets a true circle from 50%.

See it run

Hit-test the same relative corner point on a 200x100 rectangle and a 100x100 square, both with border-radius: 50%, to prove their corner curves are shaped differently.

Where this fits

This directly answers the main page's own Q&A about border-radius: 8px vs 50% on non-square elements, confirmed here via a real corner hit-test rather than just visual inspection.
