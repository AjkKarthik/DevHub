CSS

display Cannot Be Smoothly Interpolated, Only Flips

Sampling a display: none to block animation at 10%, 50%, and 90% through its timeline always returns exactly "none" or exactly "block" — never a blended value.

See it run

Sample the computed display value at several points through the animation timeline using getAnimations() — confirm it's always one of the two literal keywords.

Where this fits

This closes out three animation-timeline gotchas — what happens after an animation ends (fill-mode), where it starts (negative delay), and now a fundamental limit on what CAN be animated at all. Return to the CSS Animations overview for the full picture.
