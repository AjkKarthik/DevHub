Negative Delay Starts the Animation Mid-Cycle

animation-delay: -1s on a 2s animation starts at exactly the 50% midpoint (100px of a 0-200px growth), on the very first frame, no waiting needed.

See it run

Compare the starting width of a paused animation with no delay against one with a negative delay — the negative-delay element starts already partway through its own timeline.

Where this fits

Where the first subtopic covered what happens AFTER an animation ends, this covers where it STARTS. The final subtopic turns to a completely different kind of limitation — properties that can't be smoothly interpolated at all, no matter how the timing is configured.
