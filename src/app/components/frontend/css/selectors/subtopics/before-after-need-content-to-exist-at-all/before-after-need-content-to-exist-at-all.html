before/after Need content to Exist at All

getComputedStyle(el, '::before').content reports the literal "none" when content is never declared — proof the pseudo-element was never generated.

See it run

Compare getComputedStyle(el, '::before').content between a pseudo-element with no content declared and one with content: '' — only one was actually generated.
