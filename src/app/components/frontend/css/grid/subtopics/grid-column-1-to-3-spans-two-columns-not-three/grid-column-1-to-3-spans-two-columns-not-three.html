grid-column: 1 / 3 Spans Two Columns, Not Three

In a 3-column grid, grid-column: 1 / 3 renders at exactly 2/3 the width — line numbers, not column counts, are what those two numbers mean.

See it run

Measure an item's rendered width against the full grid width to confirm exactly how many of the three columns grid-column: 1 / 3 actually spans.
