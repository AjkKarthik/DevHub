Parent-Child Collapse Moves the Parent’s Own Box

A first child's top margin doesn't create internal space — it escapes and shifts the parent's own getBoundingClientRect() position instead.

See it run

Measure a wrapper's own top position before and after fixing parent-child collapse with overflow: hidden — the wrapper's coordinates genuinely change.

Where this fits

This closes out three box-model measurement gotchas — sibling margin collapse, outline's total layout invisibility, and now parent-child collapse literally relocating a container's own box. Return to the CSS Box Model overview for the full picture.
