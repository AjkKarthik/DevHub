A Container Cannot Query or Style Itself

The same @container rule, targeting both the container's own class and a descendant's class, only ever applies to the descendant.

See it run

Compare computed color on a container vs its child, both targeted by the identical @container rule.

Where this fits

This directly answers the main page's own quiz question and third "Common Mistake" about self-querying, confirmed here via a real computed-style comparison rather than just the spec's text.
