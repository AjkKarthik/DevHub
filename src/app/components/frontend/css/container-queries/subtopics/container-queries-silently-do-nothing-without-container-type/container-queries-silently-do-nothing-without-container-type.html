Container Queries Silently Do Nothing Without container-type

An @container rule with no container-type ancestor isn't a syntax error — it's valid CSS that can never match, with zero console warning.

See it run

Compare computed color on two identical @container-targeted children — only the one with a container-type ancestor picks up the query's style.
