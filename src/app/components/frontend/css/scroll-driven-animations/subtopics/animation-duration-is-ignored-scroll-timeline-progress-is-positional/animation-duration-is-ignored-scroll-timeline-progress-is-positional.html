animation-duration Is Ignored — Scroll Timeline Progress Is Positional

A declared animation-duration: 1s has zero effect once animation-timeline is a scroll timeline — currentTime becomes a scroll-progress percentage, not elapsed seconds.

See it run

Scrub a scroll-linked animation's currentTime as a percentage and watch every keyframe value apply instantly, despite a declared 1s duration.

Where this fits
