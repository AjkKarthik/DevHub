A Hover-Only Transition Snaps Back Instead of Reversing

Declaring transition only inside :hover animates going in — but hovering out reverts to a rule with no transition at all, so it snaps back instantly.

See it run

Compare active transitions on hover-out between an element with transition on its base rule and one with transition only inside :hover.

Where this fits

This makes the main page's own third "Common Mistake" directly measurable via the Web Animations API, confirming with a real CSSTransition object count (not just visual judgment) that the reverse direction genuinely never animates.
