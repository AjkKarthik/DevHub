Transforms Never Affect Sibling Layout Positions

Scaling an element to 2x and moving it 200px doesn't nudge its neighbor by a single pixel — transforms are purely visual, layout stays untouched.

See it run

Read a sibling's position before and after a dramatic transform is applied to its neighbor, confirming zero layout change.

Where this fits

This is the main page's own first QnA answer made directly measurable via computed layout positions. The final subtopic turns to a genuinely surprising consequence of transform's own stacking-context rule — negative z-index children can't escape a transformed parent.
