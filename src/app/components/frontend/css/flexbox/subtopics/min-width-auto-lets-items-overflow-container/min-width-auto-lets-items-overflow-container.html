min-width: auto Lets Items Overflow Their Container

A flex: 1 item with unbreakable content can render wider than its 100px container — its default min-width: auto overrides flex-shrink entirely.

See it run

Measure a flex item's rendered width against its container both with and without min-width: 0 — the overflow appears and disappears exactly on cue.
