currentSrc Reveals Which srcset Candidate Was Picked

img.src always reflects the plain fallback attribute — img.currentSrc reveals whichever srcset candidate the browser's own algorithm actually chose.

See it run

Compare img.src against img.currentSrc after the image loads — one reflects the literal attribute, the other reflects the browser's real selection.
