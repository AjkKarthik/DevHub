min() Picks the Smaller Value, Not the Larger

The same width: min(100%, 600px) rule resolves to two genuinely different pixel widths depending on which argument is currently smaller.

See it run

Place the identical min(100%, 600px) rule inside a narrow and a wide container, and measure which argument actually wins in each.

Where this fits

This establishes the core min()/max() comparison behavior. Next, see a different responsive mechanism entirely — container queries responding to a parent's own width, completely independent of the viewport.
