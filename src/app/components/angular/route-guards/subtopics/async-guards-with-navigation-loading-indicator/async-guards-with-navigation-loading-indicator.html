Async Guards with a Navigation Loading Indicator

An Observable-returning guard blocks navigation silently — wiring a loading bar to Router.events (not the guard itself) makes the wait feel intentional, not broken.

See it run

NavLoadingService listens to Router.events and shows a top loading bar for the full duration of a navigation guarded by a ~1.5s async authInitGuard — click Dashboard right after load to see it in action.
