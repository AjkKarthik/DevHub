canActivateChild for Nested Admin Sections

One guard on a parent route protects an entire nested section — and re-runs on every in-section navigation, not just on first entry.

See it run

A single roleGuard('admin') registered once via canActivateChild protects three admin child routes — try downgrading the role and navigating between children to see it re-fire without ever leaving /admin.
