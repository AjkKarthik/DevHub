Component Harnesses

Test component behaviour through a stable, semantic API — no querySelector, no internal DOM knowledge required.

Harness vs direct DOM — comparison

Without harness
// Fragile — breaks if class changes
const btn = fixture.debugElement
  .query(By.css('.mat-mdc-button'));
btn.nativeElement.click();
✗ Coupled to Material internals
✗ Breaks on Material updates
✗ Needs manual detectChanges
With harness
// Stable — semantic API
const btn = await loader.getHarness(
  MatButtonHarness.with({ text: 'Submit' })
);
await btn.click();
✓ Survives Material version bumps
✓ Readable and semantic
✓ Auto change detection
