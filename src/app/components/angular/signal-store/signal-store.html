Signal Store Pattern

Key Concepts

  • A plain @Injectable() class with state in signal() and reads via computed()
  • No NgRx needed for most apps — same reactive guarantees, far less boilerplate
  • Provided at component level (providers: [CartStore]) → destroyed with the component
  • All mutations go through methods → predictable, traceable, easy to test
