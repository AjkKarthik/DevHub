inject() — Modern Dependency Injection

A field initialiser that resolves a dependency with no constructor at all — and the only way to get DI inside Angular's functional guards, interceptors, and resolvers, which have no constructor to inject into.

See it run

A component injecting a service with a single field-initialiser line — no constructor, no parameter list.

Where this fits

inject() is how every other piece of this topic gets its dependencies — the form builder in the next subtopic, the shared service two subtopics from now, and the functional route guards after that all lean on it. Next: building the reactive form itself with FormBuilder and Validators.
