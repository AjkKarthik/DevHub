Custom & Async Validators

A sync validator is just a function. An async one adds a PENDING status, a debounce, and a switchMap — the same pattern you'd use for a live username-availability check.

See it run

Type a username — noEmoji validates synchronously as you type, while uniqueUsernameValidator debounces 300ms before checking against a fake "taken usernames" list.

Where this fits

Validators decide WHETHER a value is valid. The last subtopic covers the flags that decide WHEN to actually show that to the user — touched, dirty, and status — so errors do not flash on screen before the user has had a chance to type anything.
