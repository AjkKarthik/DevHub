FormGroup, FormControl & FormArray — The Object Model

Every reactive form is a tree of these three types, all extending AbstractControl — a single value, a named dictionary of fields, and a resizable ordered list.

See it run

A form combining all three: a plain field, a nested address FormGroup, and a dynamically resizable phones FormArray with add/remove.

Where this fits

With the object model in place, the next subtopic covers validators that check RELATIONSHIPS between fields inside one of these groups — like confirming a password field matches its confirmation field — which single-control validators cannot express.
