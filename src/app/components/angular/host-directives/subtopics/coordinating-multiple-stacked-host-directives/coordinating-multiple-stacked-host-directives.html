Coordinating Multiple Stacked Host Directives

Constructor-time injection only captures a snapshot — ongoing reactivity between stacked directives needs a publicly readable signal read inside an effect().

See it run

SnapToGridDirective injects DragDirective (listed first in the array) and reacts continuously to its position signal via effect(), snapping to the nearest grid point on every drag.

Where this fits

With cross-directive coordination covered, the final subtopic handles the case where a host directive may or may not be applied at all — optional injection.
