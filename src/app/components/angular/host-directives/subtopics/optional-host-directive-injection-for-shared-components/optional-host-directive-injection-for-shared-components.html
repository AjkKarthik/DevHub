Optional Host Directive Injection for Shared Components

A reusable directive cannot know in advance what else is composed on its host — inject(Dir, {{ '{' }} optional: true {{ '}' }}) lets it adapt instead of crashing.

See it run

AnalyticsTrackerDirective works on a plain button (click-only) and on a draggable element (click + drag distance) — the same directive class, adapting via optional injection.
