Testing Update Prompts and Install Banners

Neither SwUpdate nor beforeinstallprompt can be triggered for real in a unit test — here's the fake-Subject and synthetic-event pattern that makes both testable.

See it run

Open banners.spec.ts — SwUpdate.versionUpdates is faked with a plain Subject, and beforeinstallprompt is dispatched as a synthetic window event, so both flows run deterministically with no real service worker involved.
