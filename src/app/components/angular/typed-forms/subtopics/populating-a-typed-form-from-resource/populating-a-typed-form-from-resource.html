Populating a Typed Form from resource()

Bridging an async resource() into a typed FormGroup via effect() and patchValue(), with a dirty-check guard so a background reload never clobbers unsaved edits.

See it run

An effect patches the form from userResource.value() — but only while the form is not dirty, so editing a field before a reload preserves your changes.
