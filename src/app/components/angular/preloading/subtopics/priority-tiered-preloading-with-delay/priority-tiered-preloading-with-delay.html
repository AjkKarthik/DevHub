Priority-Tiered Preloading with Delay

Going beyond the binary preload/skip flag — a custom PreloadingStrategy that staggers preloading across priority tiers using RxJS timer().

See it run

A TieredPreloadStrategy that reads a data.preload tier ('high' | 'medium' | 'low') off each route and delays the actual load() call accordingly — open the browser console to watch the staggered schedule.
