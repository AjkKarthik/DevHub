Measuring Preload Effectiveness

Proving preloading actually helps with the Resource Timing and Navigation Timing APIs, then combining chunk preloading with a best-effort HTTP data prefetch.

See it run

MeasuredPreloadStrategy logs each chunk's preload duration and fires a best-effort data prefetch; NavTimingService logs total navigation duration for every route change so you can compare preloaded vs non-preloaded routes.

Where this fits

With tiering, testing, and measurement covered, you now have everything needed to design, verify, and prove out a custom preloading strategy end to end — head back to the topic overview to see how this connects to route resolvers and lazy loading.
