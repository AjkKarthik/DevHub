Strategy comparison

NoPreloading (default)
Initial bundle loads
… user navigates …
Lazy bundle fetches NOW ← user waits
PreloadAllModules
Initial bundle loads
Lazy bundles preloaded in background
… user navigates → instant ✓
SelectivePreload / Quicklink
Initial bundle loads
Only marked/visible routes preloaded
Best of both worlds — fast + no wasted bandwidth ✓
