How CVA wires up

writeValue(val)

Called by Angular to push a value INTO your component. Use when programmatic patchValue/setValue is called.

registerOnChange(fn)

Angular passes a callback. Call it whenever the user changes the value to notify the form.

registerOnTouched(fn)

Angular passes a callback. Call it when the user blurs/interacts to mark the control as touched.

setDisabledState(b)

Called when the form control is programmatically disabled. Update your component's visual state.
