How CVA wires up

writeValue(val)

Called by Angular to push a value INTO your component. Use when programmatic patchValue() or setValue() is called. Never call onChange() here.

registerOnChange(fn)

Angular passes a callback. Store it and call onChange(newValue) whenever the user changes the value.

registerOnTouched(fn)

Angular passes a callback. Store it and call onTouched() when the user blurs or interacts to enable error display.

setDisabledState(b)

Called when the form control is programmatically disabled. Update your component's visual state — use a signal for reactive updates.
