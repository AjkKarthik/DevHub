model() — Two-Way Binding with ModelSignal

input() flows data down, output() flows events up — model() does both at once, the same "banana in a box" [(prop)] syntax as ngModel, on your own components.

See it run

Two independent stepper components bound to the SAME parent signal via [(value)] — change either one and watch both stay in sync.

Where this fits

input/output/model cover data flowing between parent and child through bindings — the next subtopic covers reaching directly into a child's rendered view from the parent's own class, with viewChild().
