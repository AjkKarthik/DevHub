viewChild() and viewChildren()

Reach directly into a child element or component instance from the parent's own class — as a signal, with no ngAfterViewInit lifecycle hook to write.

See it run

A parent queries a child component BY TYPE (not just a template ref) and calls a method on it directly — click the button to focus the child's input.

Where this fits

viewChild() looks at the component's OWN template. The last subtopic covers the mirror image — contentChild() — for reading content the PARENT projected into this component from outside.
