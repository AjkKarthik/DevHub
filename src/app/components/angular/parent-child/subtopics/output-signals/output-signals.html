output() — Modern @Output Replacement

No EventEmitter, no Subject — a plain typed output, with the exact same emit() call site and the exact same parent-side (event)="handler($event)" binding syntax.

See it run

A counter widget emitting a changed event on every click — the parent listens with the exact same syntax as the old @Output() API.

Where this fits

input() flows data down; output() flows events up. The next subtopic combines both directions into one API — model() — for genuine two-way binding.
