Recommended learning path

① Core Angular

  1. 1Signals & State — start here; everything builds on this
  2. 2Template Syntax — interpolation, binding, control flow
  3. 3Directives — NgClass, NgStyle, custom attribute & structural
  4. 4Lifecycle Hooks — ngOnInit, ngOnDestroy, ViewChild, afterNextRender
  5. 5Pipes — built-in pipes + custom truncate + async pipe
  6. 6Input / Output — modern signal-based parent-child data flow
  7. 7Content Projection — ng-content, multi-slot, ng-template

② Forms

  1. 1Template vs Reactive — side-by-side comparison
  2. 2FormArray — dynamic add/remove fields
  3. 3Todo (guarded) — toggle login to see the route guard
  4. 4Custom Validators — sync, async, cross-field
  5. 5Zod Validation — schema-first runtime validation
  6. 6Control Value Accessor — custom form control (star rating)

③ Architecture

  1. 1Dependency Injection — singleton vs scoped, InjectionToken
  2. 2Signal Store — shopping cart, pure signal store, no NgRx
  3. 3Routing — params, guards, lazy loading, programmatic nav
  4. 4HTTP Client — HttpClient, interceptor, GET + POST
  5. 5RxJS Operators — switchMap, BehaviorSubject, combineLatest

④ Performance

  1. 1@defer Blocks — lazy-load on scroll, click, or signal
  2. 2Change Detection — Default vs OnPush side-by-side

⑤ UI & Visualisation

  1. 1Angular Material — real Material components
  2. 2Angular CDK — drag & drop, virtual scroll, clipboard
  3. 3Animations — trigger, keyframes, stagger
  4. 4Charts (Chart.js) — bar, line, doughnut with live data
  5. 5Tailwind CSS — class binding, dark mode, @apply

⑥ Third-party Libraries

  1. 1AG Grid — enterprise data grid, CSV export
  2. 2TanStack Query — server state, caching, mutations
  3. 3date-fns — format, date math, relative time
  4. 4Testing — TestBed, @testing-library, signal assertions
