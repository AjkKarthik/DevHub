Key testing-library principles

Query by role, not selector

getByRole('button', name:) — matches what screen readers see. More resilient to markup changes.

user-event over fireEvent

userEvent.click/type simulates real browser events including focus, blur, keyboard. fireEvent is too low-level.

Test behaviour, not implementation

Don't access component internals — test what the user sees and does. Refactoring internal state shouldn't break tests.

Signals read immediately

Unlike markForCheck, signal reads are synchronous — no detectChanges needed between signal read and assertion.
