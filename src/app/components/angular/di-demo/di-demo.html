Angular's DI system — singleton services, component-scoped providers, InjectionToken, and hierarchical resolution.

Root Singleton vs Component-Scoped Service

SharedCounterService providedIn: 'root'

Same instance everywhere in the app. All components share state.

{{ shared.count() }}
ScopedCounterService providers: [...]

New instance per component. Destroyed with the component.

InjectionToken

Hierarchical DI Resolution

Root Injector (Platform) providedIn: 'root' services live here
↓ walks up if not found
App Component Injector providers: [] in AppComponent
↓
Feature Component Injector providers: [ScopedService] — overrides root for subtree
↓
Child Component inject(ScopedService) → gets FEATURE instance, not root
