What Are Interceptors? — Middleware for Every HTTP Call

One plain function, registered once, that touches every outgoing request and incoming response in the app — request order forward, response order reverse.

See it run

A logging interceptor that times every request — check the browser console after clicking Load.

Where this fits

The most common real interceptor is the one that attaches an auth token to every request — including the trickiest part: refreshing an expired token exactly once, even when several requests 401 at the same moment.
