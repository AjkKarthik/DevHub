What Is a Signal?

Before computed(), before effect(), before any of the advanced patterns — this is the one idea everything else in Angular's reactivity system is built on. Start here if you've never written signal() before.

Where this fits

signal() is the foundation — a plain, writable, synchronous value. On its own it's not much more than a variable with extra bookkeeping. The reason Angular's signal system is powerful is what gets built on top of it: computed() derives new values automatically whenever a signal it reads changes, and effect() runs side effects the same way. Both of those only make sense once signal() itself is second nature — which is exactly why this is subtopic one.
