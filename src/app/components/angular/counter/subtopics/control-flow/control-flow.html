@if and @for — Control Flow with Signals

The built-in control flow blocks read signals exactly like any other expression — no pipes, no subscriptions. This is where signal() and computed() actually show up in the templates you write every day.

See it run

A filtered task list — toggle "Show completed" to see @for react to a computed-style filtered view, and watch @empty kick in when the filtered list is empty.

Where this fits

You now know how all three signal primitives connect to what actually renders on screen: signal() holds the state, computed() derives a value from it, and @if/@for read either one directly to decide what appears in the DOM.
