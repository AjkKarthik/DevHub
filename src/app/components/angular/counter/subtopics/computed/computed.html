computed() — Derived State

Once you've got a signal, you'll almost immediately want a second value that's based on it. This is how Angular keeps that second value correct automatically, instead of you updating it by hand.

See it run

One writable signal, two computed values derived from it. Edit the code and watch both derived values stay correct without any extra work.

Where this fits

signal() gave you a single source of truth. computed() lets you build as many derived views of that truth as your UI needs, without ever risking them getting out of sync — because they're not separate values, they're recalculated from the original every time it's needed. Next up: effect(), which uses the exact same dependency-tracking mechanism, but for side effects instead of derived values.
