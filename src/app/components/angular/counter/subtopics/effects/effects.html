effect() — Reactive Side Effects

signal() holds a value, computed() derives a value — effect() is for everything else: logging, persistence, DOM updates, and anything that reacts to a change without itself being a value.

See it run

Click the button, then check the log list (and your browser console) — the effect runs automatically on every change, no subscription required.

Where this fits

You now have all three core primitives: signal() holds state, computed() derives values from it, and effect() reacts to it with side effects. Everything else in Angular's signal system — linkedSignal(), the service patterns, the RxJS interop — is built by combining these three in different ways.
