OnPush Trigger Rules

✅New input() / @Input() reference — replace array/object, don't mutate
✅Event inside component — any DOM event on this component's template
✅async pipe emits — Observable emits via | async
✅signal() changes — Angular 17+ auto-tracks signal reads in templates
✅markForCheck() — manual schedule via ChangeDetectorRef
❌Mutating @Input() object — same reference, OnPush won't detect it
❌setTimeout outside zone — use signals or NgZone.run() + markForCheck()
