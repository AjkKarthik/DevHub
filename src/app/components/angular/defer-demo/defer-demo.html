@defer — Deferred Loading

Key Concepts

  • @defer — splits a component into its own lazy JS chunk, downloaded only when triggered
  • on viewport — loads when the placeholder scrolls into view
  • on interaction — loads on first click or keydown inside the placeholder
  • on idle — loads when the browser is idle (the default)
  • when expr — loads when a signal or expression becomes truthy
  • @placeholder — shown before trigger; @loading — shown while downloading; @error — shown on failure

on viewport — loads when scrolled into view

Open DevTools → Network to see the heavy-chart chunk download when you scroll here.

@defer (on viewport) { } @placeholder {
📊 Chart will load when visible
} @loading (minimum 400ms) {
⏳ Loading chart bundle…
} @error {
Failed to load chart.
}

on interaction — loads on first click

@defer (on interaction) { } @placeholder {
🖱 Click here to load the chart
} @loading (minimum 300ms) {
⏳ Loading…
}

when — programmatic trigger via a signal

@defer (when showOnDemand()) { } @placeholder {
Chart not loaded yet — click the button above
