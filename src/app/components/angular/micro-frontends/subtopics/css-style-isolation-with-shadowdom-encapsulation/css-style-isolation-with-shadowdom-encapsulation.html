CSS Style Isolation with ShadowDom Encapsulation

Emulated encapsulation only protects against other Angular components in the SAME app — ShadowDom creates a true browser-level boundary against another MFE's global styles.

See it run

Two buttons on the same page with the same global stylesheet loaded — the Emulated one gets styled crimson by global CSS, the ShadowDom one is fully isolated but still inherits a shared CSS custom property.
