Recovering from Component Rendering Errors

Angular has no built-in way to retry a failed render — the practical fix is destroying the crashed instance and mounting a genuinely fresh one.

See it run

RiskyWidgetComponent crashes on null data — "Fix data and remount" destroys the crashed instance via @if and creates a fresh one with valid data.
