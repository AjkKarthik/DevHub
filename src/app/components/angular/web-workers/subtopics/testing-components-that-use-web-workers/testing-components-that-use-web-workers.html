Testing Components That Use Web Workers

jsdom has no Worker implementation at all — this page shows the injectable-factory pattern that makes worker-dependent components testable without a real thread.

See it run

Open sum.component.spec.ts — a MockWorker satisfies the same surface a real Worker exposes, letting tests trigger responses and errors synchronously and assert cleanup on every exit path.

Where this fits

Testing covers a single worker. The next subtopic scales up to a POOL of workers for parallelising many tasks at once, and the one after that covers debugging real workers in DevTools.
