Pipes

Transform data in templates — date, currency, number, case, slice, JSON, async, and custom pipes with the PipeTransform interface.

Code Examples

Date Pipe

now | date {{ now | date }}
now | date:'shortDate' {{ now | date:'shortDate' }}
now | date:'shortTime' {{ now | date:'shortTime' }}
now | date:'fullDate' {{ now | date:'fullDate' }}
now | date:'{{ customFormat() }}' {{ now | date:customFormat() }}

Currency, Number & Percent Pipes

amount | currency {{ amount() | currency }}
amount | currency:currencyCode {{ amount() | currency:currencyCode() }}
amount | number:'1.0-0' {{ amount() | number:'1.0-0' }}
amount | number:'1.2-4' {{ amount() | number:'1.2-4' }}
percent | percent:'1.1-2' {{ percent() | percent:'1.1-2' }}

Case Pipes

| uppercase {{ rawText() | uppercase }}
| lowercase {{ rawText() | lowercase }}
| titlecase {{ rawText() | titlecase }}
