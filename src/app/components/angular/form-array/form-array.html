FormArray — Dynamic Fields

Add and remove form rows at runtime with FormArray — perfect for email lists, phone numbers, skills, and any repeating field group.

Code Examples

Key Concepts

  • FormArray — an array of controls you can add/remove at runtime
  • fb.array([...]) — creates it; each item can be a FormControl or FormGroup
  • formArray.push(ctrl) / removeAt(i) — mutate the array
  • formArrayName directive in the template binds to it
  • form.markAllAsTouched() — trigger all validators at once on submit
