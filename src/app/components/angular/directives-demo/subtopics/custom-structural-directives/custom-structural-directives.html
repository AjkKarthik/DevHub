Custom Structural Directives

TemplateRef and ViewContainerRef are the entire mechanism — the same two ingredients that power *ngIf and *ngFor internally, available for your own reusable logic.

See it run

A custom *appRepeat="5" directive rendering a template N times, exposing both an implicit value and a named index context property.

Where this fits

Structural and attribute directives are two separate concerns — the last subtopic covers bundling multiple directives (of either kind) onto one host without the consumer having to add each one individually, via the Directive Composition API.
