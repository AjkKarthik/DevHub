HTTP Client

Key Concepts

  • provideHttpClient(withInterceptors([...])) in app.config.ts
  • inject(HttpClient) — no constructor needed
  • toSignal(observable$) — wraps an Observable into a signal (auto-unsubscribes on destroy)
  • HttpInterceptorFn — functional interceptor, clones the request before forwarding
  • TruncatePipe — custom pipe, shortens long strings: {{ '{}' | truncate:45 }}
  • appHighlight — custom directive, adds background on hover
