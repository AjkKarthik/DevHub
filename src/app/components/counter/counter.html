Signals & State

Key Concepts

  • signal(value) — creates a reactive value. Read it by calling it: count()
  • signal.set(v) — replace the value; signal.update(fn) — derive from current
  • computed(() => ...) — derived value, recalculates when its signal deps change
  • effect(() => ...) — side effect that re-runs whenever any read signal changes
  • @if / @else if / @else — new block-based control flow (replaces *ngIf)
  • @for (x of list; track x.id) — replaces *ngFor
